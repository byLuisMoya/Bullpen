# Contributing

Thanks for your interest! Bullpen is in early development, so expect things to move fast.

- Open an issue before large changes so we can agree on the approach.
- `make test` must pass. New behaviour needs a test (Swift Testing).
- Keep the app light: no Electron, no 3D, no background work while views are hidden.
- Code and commit messages in English; docs/PLAN.md is in Spanish.
- Art contributions must be CC0 or CC BY 4.0 so they can live in this public repository.
